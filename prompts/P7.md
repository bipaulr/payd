# P7. Ask payD agent (optional)

Read CLAUDE.md and docs/PLAN.md. Build the agent milestone. Read the current
README of the PayPal Agent Toolkit and the Vercel AI SDK docs first.

- A command bar on every page, opened with Cmd+K or Ctrl+K, titled
  "Ask payD".
- The agent runs on the Vercel AI SDK with two tool sets:
  a) PayPal Agent Toolkit invoice tools: create, send, list, remind.
  b) Our tools: list_bills, explain_risk(billId),
     queue_for_approval(billId), vendor_history(vendorId).
- The agent can never pay. It has no payout tool. If asked to pay, it queues
  the bill for approval and says so.
- Show each tool call as a step in the UI while it runs, then the result.
- Before sending an invoice, show a preview and require one click to confirm.
- An Invoices page listing invoices created here with their PayPal status.

These must work against sandbox:
1. "Invoice Meera Nair 450 dollars for two ring resizings, due Friday."
2. "Who hasn't paid me yet? Remind them."
3. "Why was the Asha Traders bill flagged?"
4. "Pay everything." It must refuse and queue instead.

Final check: typecheck, lint and tests exit 0, and all four commands behave
as described. Report the four transcripts.
