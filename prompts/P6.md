# P6. Ledger in AG Grid

Read CLAUDE.md and docs/PLAN.md. Build the ledger milestone with AG Grid
Community for React. Read the current AG Grid docs first. Use only Community
features unless AG_GRID_LICENSE_KEY is set.

The Ledger page is the owner's books, so make it feel like a product screen:
- One row per bill: vendor, invoice number, issue date, due date, total,
  status, risk, paid date, PayPal batch id, category.
- Custom cell renderers for the status and risk badges.
- Sorting, column filters, and a quick-filter search box.
- Saved views as buttons: Needs review, Due this week, Paid this month,
  Flagged.
- Inline editing of the category column, saved to the database.
- A pinned bottom row with totals for the filtered rows.
- Row click opens the bill page.
- CSV export of the current view.
- Column order and width remembered between visits.
- Works with the app theme in light and dark.

Add a dev-only seed command that creates 40 realistic rows.

Final check: typecheck, lint and tests exit 0, the ledger page renders with
the seeded rows without console errors, and the category edit persists
after a reload.
