# P10. Final audit

ultrathink. Read CLAUDE.md and docs/PLAN.md. Audit payD as a hackathon judge
who wants to break it, then fix what you find. Bug fixes only.

1. Clone the repo into a temp folder and follow the README exactly. Fix any
   step that fails or is missing.
2. Run the demo story from a clean reset, on APP_URL if it is set and
   reachable, otherwise locally.
3. Try to pay a bill twice: double click, two tabs, replayed webhook, retry
   after a timeout. No path may create a second payout.
4. Try to pay without approval, including through the agent if it exists.
5. Upload a huge file, a non-bill photo, an empty PDF and a corrupt file.
6. Break the model call and the PayPal call on purpose. The UI must explain
   what happened and let the user retry.
7. Scan the repo and git history for secrets.
8. Confirm no code path can reach PayPal live endpoints.

Final check: typecheck, lint and tests exit 0, and the report contains a
table of issue, severity, fixed or not, plus a list of what you could not
verify.
