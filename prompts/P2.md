# P2. PayPal core

Read CLAUDE.md and docs/PLAN.md. Build the PayPal core milestone. Open the
current PayPal docs for each call before you write it.

Build in lib/paypal:
- getAccessToken(): client credentials against sandbox, cached until expiry.
- createPayout(bill): one payout item to the vendor's PayPal email, with a
  sender_batch_id derived from the bill id so a retry can never pay twice.
- getPayout(batchId): current status, used as a fallback when webhooks are
  late.
- verifyWebhook(request): PayPal signature verification.

Build /api/webhooks/paypal:
- Verify the signature, store the event, ignore events already stored, and
  move the Payout and Bill to paid or failed.

Also:
- A payBill(billId) service that refuses unless the bill has a recorded
  Approval and is in the approved state. Use a database transaction so two
  clicks cannot create two payouts.
- scripts/payout-smoke.ts that sends $1.00 to PAYOUT_SMOKE_EMAIL and prints
  the batch status, polling getPayout until it settles or 60 seconds pass.
- Unit tests with mocked HTTP for: double pay, missing approval, replayed
  webhook, bad signature.

Run the smoke script against sandbox. If Payouts is not enabled for this
sandbox app or the call is refused, write BLOCKED.md with the exact
response and stop. Do not build a workaround.

Final check: typecheck, lint and tests exit 0, and the smoke script shows a
successful sandbox payout. Report the batch id.
